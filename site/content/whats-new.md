# What's new

WorldPainter Modernised starts from WorldPainter 2.27, which supports Minecraft 1.20.5 to 26.x, and keeps everything it does. This page lists what it adds; each feature has a page of its own.

## Generate

- **[Node graph](node-graph.html)**: generate complete worlds from noise, erosion, rivers, lakes, masks and painters, with a live preview. 36 kinds of nodes, and examples to start from.
- **[Floating islands](tutorial-floating-islands.html)**: a node which builds islands in the sky.
- **[Procedural terrain](node-graph.html#procedural-terrain)**: a simpler dialog with stacked noise layers and eight presets.
- **[Edge blending](edge-blending.html)**: the map no longer ends in a cliff; its edges go over smoothly into the land around it.

## See

- **[Integrated 3D view](3d-view.html)**: in the main window, with five colour modes, a block by block mode, sun and shadows, and everything about the block under the mouse.
- **[Surroundings](surroundings-and-seeds.html)**: the biomes Minecraft will generate around the map, shown faintly around it.

## Build

- **[Paths](paths.html)**: roads through points you click, following the land, with bridges and tunnels.
- **[Seed search](surroundings-and-seeds.html#find-a-matching-seed)**: find a seed for which the land around the map matches its edges, and blend the edges into it.
- **[Tree pack and material mixes](trees-and-materials.html)**: nine kinds of custom trees and eighteen mixes of blocks, included.
- **Terrain stamps**: brushes shaped like a peak, a range, a volcano, a crater rim, a mesa, dunes…

## Use

- **[A new interface](interface.html)**: light and dark themes, clear panels, tools grouped by what they do, explanations on hover, a dotted canvas, and a unified title bar on macOS.
- **Java 21**, native applications for macOS, Windows and Linux, and more memory for large maps.
