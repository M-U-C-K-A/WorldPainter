# Roadmap

WorldPainter Modernised is released as previews on [GitHub Releases](https://github.com/M-U-C-K-A/WorldPainter/releases): it is used to make real maps, but it is still being tested. This is what is being worked on.

The roadmap is followed on GitHub, on the [roadmap board](https://github.com/users/M-U-C-K-A/projects/4), with an [issue](https://github.com/M-U-C-K-A/WorldPainter/issues) per item and a [milestone](https://github.com/M-U-C-K-A/WorldPainter/milestones) per version: comment on them, or give a 👍 to the ones that matter to you.

## Done

- [x] [Clearer settings windows](https://github.com/M-U-C-K-A/WorldPainter/issues/20): an illustrated banner, and settings grouped in cards with explanations and badges
- [x] Preview releases on GitHub, with versions and release notes
- [x] Brush settings which stay when switching tools, with limits by map selection, by height on a scale you can drag, by several terrain types or layers at once, and by slope, with undo
- [x] Clearer cards on hover, with what the mouse and keys do and pictures of the brush options
- [x] Better shaders in the 3D view: sunlight and skylight, shaded valleys, new water and sky
- [x] Side panels which fold away, and palettes which keep their size when resizing
- [x] Round maps blended into their surroundings
- [x] Undo for the layers created by the node graph and the Path tool (trees, bridges, tunnels, floating islands)
- [x] Node graph with 36 kinds of nodes, examples and `.wpgraph` files
- [x] Floating islands node
- [x] Integrated 3D view with colour modes, blocks and shaders
- [x] Surroundings, seed search and blending into the seed
- [x] Paths with bridges and tunnels
- [x] Tree pack and material mixes
- [x] New interface with light and dark themes

Ideas and bug reports are welcome on [GitHub](https://github.com/M-U-C-K-A/WorldPainter/issues).
